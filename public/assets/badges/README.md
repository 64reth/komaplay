# KOMA key-ring access badges

These monochrome badges are informational access indicators. More keys mean broader operational responsibility; they are not rewards, ranks, or public reputation scores.

| Asset | Meaning | Suggested alt text |
| --- | --- | --- |
| `key-ring-member.svg` | Member: Workshop and community contribution access | `Member — Workshop access` |
| `key-ring-editorial-contributor.svg` | Editorial Contributor: canonical panel creation and submission | `Editorial Contributor — can create and submit panels` |
| `key-ring-moderator.svg` | Moderator: review, publishing, and Open Panel moderation | `Moderator — can review, publish, and moderate` |
| `key-ring-admin.svg` | Admin: user management and site operations | `Admin — can manage users and site operations` |

The SVGs include internal `<title>` and `<desc>` elements for direct use. When used beside a visible role label, treat the image as decorative (`alt=""`) and put the full meaning on the surrounding text or tooltip to avoid duplicate announcements.

There is intentionally no Owner/master-key asset. Owner is not a live KOMA permission.
